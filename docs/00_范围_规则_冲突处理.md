# 00｜产品范围、规则与冲突处理

## 0.1 产品画像

《我是CEO》：竖屏2D、主要靠手指点击的轻策略公司经营模拟游戏。单局从零创建一家企业，经营**一个初始主营业务**，比较招聘人才，设置多个支持部门，利用自动经营和年度结算争取连续3年利润为正、持续经营并提高经营年限与总资产本地模拟排名。可挂机，可加速，亏损不立即破产，可主动永久关闭公司重新开始。

目标：1分钟理解页面；首次必需创建与首聘尽量少于约2分钟（体验测试目标）；玩家可短时上线做决策，离线仍能获得安全且可追溯的进度。游戏不会自动要求玩家“必须升级到集团”。

## 0.3 明确不做（不得被Agent自行“顺手加上”）

跨行业、新增业务线、子公司、母集团、共享服务中心、股权/上市、并购、贷款/借款利息、真实竞争公司AI、真实在线排名、广告、内购、多人、云存档、复杂生产/库存/税收、员工关系树、技能天赋树、3D办公室、NPC步行动画、强制任务关卡、对话式大模型接口、外部动态经营参数下发。**允许为未来扩展预留接口，不允许实际开发第二阶段玩法。**

## 0.4 关键术语

- **经营年度**：玩家观察财务和排名的完整周期；内部由12个离散月份累加。
- **收入口径**：对外订单在模拟中完成后确认的营业收入，MVP假设当月全部收现；不做应收账款。
- **利润**：收入扣除当期损益项目；不包含创业资本注入、不直接把资本性扩张投资全额扣利润。
- **现金**：可支付经营费用的余额；不等同于利润。
- **总资产**：现金+未折旧业务资产；MVP无负债模型，不代表企业市值。
- **成本中心**：HR、采购、市场、客服、财务；部门费用在财务中明确列示。
- **手动锁定**：玩家锁定某部门目标人数，自动经营不会擅自招聘/裁员该部门。
- **重开**：永久结束当前本地经营run，产生新runId；平台身份保持不变。

## 0.5 游戏不变量（测试全部验证）

1. 同一 `(runId, year, month)` 只能结算一次。
2. 同一 `commandId` 招聘/裁员/建部门/追加资本最多产生一次费用或收益。
3. 本局启动资本仅注资一次；重开属于新run，每轮一次。
4. 年度利润=年收入−全部当期损益费用；现金期末−现金期初=净经营收付−资本支出+资本注入。
5. 工资计入已实际在岗的月份；招聘/裁员默认**次月生效**，费用在确认时立即支付并在本年度记账。
6. 现金、未折旧资产账面价值不得为负；财务数据都以整数元存储，展示才格式化。
7. 采购/客服/财务节约从真实对应成本扣除，不增加虚构收入；每种可节约成本下限为0。
8. 玩家明确锁定的人数与年度支出上限，不被自动决策修改；**不自动裁员**。
9. 离线结算不得自动执行重大投资、关闭公司、裁员或领取一次性重整金。
10. 关闭公司后的旧runId任务、旧保存回调无权覆盖新档。
11. 对本地存档无法恢复、认证失败、平台接口不可用，必须展示明确恢复/重试/本地游玩策略，不允许静默清空存档。
12. 所有经营建议可由同一条计算规则推导；不能伪造“预计提升”。

## 0.6 从V0.9纠正的实现歧义

- 年度数据中“每月工资”和“年薪”统一：工资候选显示**月薪**，所有月度工资按在岗月计入；第1年入职在游戏时钟开始之前，可正常产生12个月工资。
- 原先“总资产含业务资产、投资从次年折旧”保留；但**未实现贷款/债务**，不能在困境期使用负现金、自动借贷。进入困难时冻结新支出并等待恢复处理。
- 原先“单次离线最多3年”明确为最多24小时等效离线处理，超过部分不累积到未来补领；暂停状态不累计离线进度。
- 经营报告同时标记“当年已结算”和“进行中预估”，避免正在经营的数字被误认为全年审定结果。
- 前5年为可选指导，不锁定年份、部门购买或具体盈利曲线；标准首年样例只是可复现校验数据，不是所有玩家的保底收益。
- 存档容量来自官方本地缓存限制：按年保留摘要、限制最近月账本，**不能无限存每个人每个月的流水**。
