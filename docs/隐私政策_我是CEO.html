一、我们是谁

《我是CEO》是一款由【开发者名称】独立开发的单机模拟经营游戏，通过 TapTap 平台以「小游戏」形式发布。本政策说明我们在提供服务过程中如何处理你的信息。

二、我们收集的信息（极少）

本游戏的设计理念是「数据不出设备」：

场景涉及信息处理方式
游戏存档（公司、员工、财务、设置）全部经营数据只存储在你的设备本地，不上传、不备份到任何服务器；卸载或清除游戏数据即彻底删除
TapTap 登录一次性登录凭证 code游戏将 code 发送至我们部署在 LeanCloud（TapTap 开发者服务）的登录接口，换取短期会话令牌（有效期 1 小时）。服务端仅在内存中临时持有平台返回的用户标识（openid），不落盘、不展示、不用于任何其他目的，实例回收即消失
音频、画面设置开关状态仅保存在设备本地

我们不会收集：通讯录、精确位置、相册、麦克风、摄像头、设备指纹（IMEI/IDFA 等）、剪切板内容，也不会绘制用户画像。

三、第三方 SDK 说明

本游戏仅接入 TapTap 提供的登录能力（用于满足平台账号要求），不接入任何广告 SDK、统计埋点 SDK、推送 SDK 或支付 SDK。TapTap 平台在你使用其账号登录时的信息处理，适用 TapTap 隐私政策（以其官网当期版本为准）。

四、信息的存储与保护

  • 经营数据：仅存于你的设备本地，传输为零。
  • 登录交换：通过 HTTPS 加密传输；服务端不持久化任何可识别个人身份的信息。
  • 我们没有任何账号体系、排行榜上传、云存档或聊天功能，因此不存在你的经营数据被泄露的服务端风险。

五、未成年人保护

本游戏不含内购、广告与社交功能。按照平台要求，未成年人的游戏时长与登录限制由 TapTap 平台防沉迷系统统一执行。我们建议未成年玩家在监护人指导下合理安排游戏时间。

六、你的权利

  • 删除数据：卸载游戏或在系统设置中清除游戏数据，即可删除全部本地存档与设置。
  • 撤回同意：首次启动的隐私告知弹窗中，你可以选择不同意并退出游戏；同意后也可通过卸载随时退出。
  • 查询与更正：我们不持有你的任何个人信息副本，因此无服务端数据可供查询或更正；如有疑问可通过【联系邮箱】联系我们。

七、政策更新

如本政策发生变更，我们将在本页面（【隐私政策页面地址】）更新并在游戏内作出提示。重大变更时，会在游戏启动时再次征得你的同意。
