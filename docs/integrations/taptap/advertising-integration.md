# TapTap 广告接入

官方广告指南提示：该指南覆盖星火、H5 小游戏和 TapTap 制造；Tap 小游戏与 APK 应接入 Dirichlet 广告联盟。不得把 H5/制造的广告 SDK 或广告位接口用于本项目 Tap 小游戏。

《我是CEO》当前确定的产品范围只允许此前已确认的可选激励视频：每日提示一次、可跳过继续经营、观看完成后仅免一次性招聘费、仍支付月薪、次月生效、首聘不参与。该授权是产品设计边界，不代表平台广告能力已开通，也不授权开通账户、财务主体、广告位或发布广告。

上线前核对：

1. 查当前小游戏广告/联盟官方文档和平台接入版本；确认 Dirichlet 是否为该项目形态正确路线。
2. 开发者本人完成联盟/财务资质和广告开通；不要让 Agent 填真实收款资料。
3. 仅按产品既定规则接激励视频，广告加载/播放失败不阻塞经营，不发放未完成奖励。
4. 真机验证成功、失败、跳过、重复回调和奖励幂等；确认后台报表/结算再判断上线状态。

来源：[官方小游戏广告接入指南](https://developer.taptap.cn/minigameapidoc/quick-start/mcp-guide/ad-integration-guide/)（2026-11-04 页面核验）。
