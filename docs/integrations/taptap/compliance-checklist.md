# TapTap 上架合规核对清单

本清单是准备入口，不构成法律意见或平台批准。材料类型以当前形态和开发者后台显示为准。

- [ ] 开发者账号实名/主体认证完成，应用归属和协作者权限正确。
- [ ] Tap 小游戏前置备案已按官方流程完成；确认个人开发者可用主体、所需身份证明和材料要求。不要把“个人可发布”误解成免备案/免审核。
- [ ] 核对当前形态是否要求版号、软件著作权、ICP备案或其他行政材料；不得跨 H5、小游戏、APK 推定。
- [ ] 隐私政策链接可访问且与实际数据、平台 SDK 清单一致；首次收集前的告知和同意流程符合要求。
- [ ] TapTap 登录、广告、统计 SDK 的隐私声明和数据处理逐项核对；不在前端放服务端密钥。
- [ ] 商店简介、图标、宣传图、截图和视频确为当前版本真实内容且有授权；检查各形态尺寸要求。
- [ ] 自测正常、存档/离线策略清楚、无白屏/死循环；包体来自最终构建且符合后台当期格式/大小要求。
- [ ] 对未成年人、防沉迷、内容分级、用户数据和广告规范，根据游戏形态查最新官方要求。
- [ ] 审核通过、正式上线、广告收益结算分开记录；任一未验证不可称已上架。

来源：[小游戏官方文档索引](https://developer.taptap.cn/minigameapidoc/quick-start/document-guide/)、[TapTap AI 开发者指南](https://developer.taptap.cn/agents/)。平台规定会变，提交材料前重新检查。
