# 《我是CEO》TapTap 发布路径

## 项目现状和形态

工程标识为 Cocos Creator `3.8.8` + TypeScript（`package.json`），项目规范指向普通 Tap 小游戏。Tap 小游戏使用平台适配构建产物（常见为专用 ZIP/WebGL 转换包），不能仅凭工程引擎、`index.html` 或 ZIP 后缀认作 H5。每次发布前核实 `build/` 产物清单、转换工具版本和控制台“游玩提供方式”。

建议路线：保留 Cocos Creator 业务工程 → 使用官方当期支持的 Tap 小游戏适配/转换流程 → 本地检查输出目录、分包和资源 → 控制台上传/自测 → 补小游戏备案和商店资料 → 测试 → 人工审核。官方 CLI 当前帮助里出现 `upload-mini-app-package`，但官网 AI 指南称小游戏上传目前在控制台；在 CLI schema 和真实账号许可确认前继续使用明确的控制台流程。

## 形态区别

- **H5**：平台域名托管网页；小游戏 MCP 安装指南明确支持该路线。
- **Tap 小游戏 (WebGL)**：按小游戏 API 和引擎适配器生成专用产物，和 H5 Web 上传不是同一规范。当前项目目标。
- **TapTap 制造**：在制造编辑器/本地插件中创作并走其发布链路，不适用当前工程直接推定。
- **APK/PC**：安装包分发和 TapSDK 路径；不能把 APK 包体命令当小游戏上传命令。

## 限制

具体文件格式、单包/总包体限制、版本号约束、分包限制会依平台规则更新，本文件不固化未经当前后台确认的数字。创建游戏、上传任何文件、修改资料、开测试、提审和发布均属外部写操作，执行前展示草案并等待用户明确确认。本次均未执行。
