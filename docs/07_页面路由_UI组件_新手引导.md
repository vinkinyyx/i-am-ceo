# 07｜UI页面、竖屏布局、触屏交互与新手引导

## 7.1 统一视觉与交互

- 设计基准：竖屏宽375逻辑像素、高812逻辑像素；适配360×640、390×844、428×926等。Cocos Canvas Fit Width优先，随安全区域调整顶部状态栏及底部导航，不允许内容被刘海/手势栏遮挡。
- 色彩建议：浅色低对比背景 + 深色文字 + 统一财务强调色；亏损用红色、盈利用绿色，但同时显示正负号和文字，不能只靠颜色。字重/字号保证移动端可读。正文建议14—16逻辑像素，核心财务数值22—28，辅助说明≥12。
- 触控目标**至少44×44逻辑像素**，相邻可点击项间距≥8；单手点击可达；长表使用ScrollView，横向不溢出。列表超过30条时复用/虚拟化。
- 不做绚丽过场、走路人物、动态办公室。保留必要的按钮按下、弹窗入场（建议≤200ms，可降级为无动画）、数值变化反馈。
- 每个页面显示实际数据状态：Loading/Empty/Normal/Error/ReadOnly；所有需花钱的按钮确认前显示资金变化。业务数据不可由动画状态决定。
- 公司/CEO名称、员工姓名、公司名称列表均用Cocos Label渲染，超长截断与二级详情展示全文；自定义输入使用合规输入组件，不引用DOM输入框。

## 7.3 核心屏幕详细规格

### S01 公司创建

- 顶部：游戏名《我是CEO》、步骤条“1/3 创建公司”。
- 第1卡：选行业，3项竖排单选卡，展示一句行业特色与首年参考成本提醒（不是承诺收益）。
- 第2卡：随机公司名3候选单选、`换一批`、`自定义名称`输入；若输入有效自定义名，优先采用输入。
- 底部固定按钮`下一步：创建CEO`，无有效公司名/行业时禁用并给出错误原因。
- 异常：名称违规/重复点/输入法遮挡/返回再进，不能丢前一步有效输入。

### S02 CEO创建

- 顶部步骤“2/3”；名字输入或随机，3性格卡单选，三个属性条初始均50，说明不同成长偏向。
- 底部：`上一步`（保留公司名） / `下一步：招聘员工`。
- 点击下一步执行创建run事务并只注资一次；如果被中断重启，直接返回已存在run的初聘步骤。

### S03 初始招聘

- 步骤“3/3”，`已录用 0/2`；3候选列表，每卡头像、名、性格、能力/潜力/协作、工资、招聘费。
- 可点任一人展开对比，点`录用`前明确“现在支付招聘费¥X/下年工资约¥Y”。
- 录用第1人后金额即时扣除并保存，继续提供下一个稳定Offer；2/2后出现`进入公司`。
- 退出/重启保留首聘1/2，不重复扣招聘费；不能跳过实际必需2人录用，但教学解说可以跳过。

### T01 公司首页

布局（从上到下）`
[安全区/公司名/设置] → [CEO小卡+经营第N年] → [资金/营收/利润 3列统计] → [今年月份进度条+暂停/1×/2×/5×] → [业务简报+经营策略] → [经营诊断/年度报告入口] → [4Tab固定底部]`。

- 实时卡显示**进行中累计收入**及**预计全年利润**，标签必须标明“预计”；已结束年度数据在报告内。
- 点击现金/利润旁“?”出现简短解释；点击经营策略弹三选项；点击风险卡进入D07。
- 从首页可以暂停、倍速；切换前台/后台需存档，不能重复年结。

### T02 部门

- 顶部“主营业务部”（始终显示、人数、预计产能、订单缺口、可点击`扩大产能`），下方“支持部门”。
- 未设部门卡：图标、作用、费用、适配提醒、创建；已设卡显示人数、本年累计节省/毛利增益、工资、净贡献与招聘操作。
- 点击建部门弹确认，必须标明创建后**0员工无效益**和一次性1万元费用。
- 点击自动/手动模式需解释“手动锁定不会自动补人”；设置目标人数不会自动裁员。

### T03 人才

- 汇总本期员工总数/预计年工资；筛选全部/主营/支持部门。
- 员工卡单击打开D02；右上`招聘`先选目标部门，生成3候选。
- 裁员确认必须展示补偿月数/金额、下一年工资节省/可能降低的收入；确认与取消有明显视觉区分。
- 员工数量0的部门显示可用“去招聘”入口。

### T04 排行

- 分段“总资产榜/经营年限榜”，列表名次、公司名、资产/年限；我方行固定突出，但不可使用虚假真实玩家头像/真实企业标识。
- 模拟竞企随年进展，用户重开时本局排行重新初始化；支持点击说明“本榜由模拟公司组成，非真实在线排名”。

### D01 年度财务报告

内容必须包括收入、直接成本、其他运营、售后、固定费、全部工资、招聘、裁员、设部、事件、折旧、年度利润、期初/末现金、资产；如字段为0，可折叠不应悄悄改变总计。展示今年经营事件和最多1条经营建议。报告可以关闭，历史可再打开；完成第1年时展示新手T06。可查看最近100年摘要。

## 7.4 六步逐点击新手引导（TUT-01~06）

| 步骤 | 触发时机 | 引导高亮真实控件 | 通过条件 | 跳过时处理 |
|---|---|---|---|---|
| TUT-01 公司命名 | S01进入 | 候选名称/输入框 | 有效名称选中 | 只关闭提示，仍须提供名称 |
| TUT-02 CEO设定 | S02进入 | 姓名/性格 | 两者完成 | 仍须设置CEO |
| TUT-03 首聘员工 | S03进入 | 对比卡及录用按钮 | 实际录用2人 | 仍须录用2人 |
| TUT-04 三大指标 | 首次进入T01 | 现金、营业额、利润的“?” | 点击一次或完成提示 | 关闭解释 |
| TUT-05 开始经营 | T01首次进入 | 开始经营/倍速 | 时钟开始推进 | 可直接启动并结束本步 |
| TUT-06 首年报告 | 第1年首次结算 | 年度利润/现金变动字段 | 点击报告“知道了” | 关闭解说，年报保留 |

教程记录`completedSteps`、`skipped`, `lastKnownStep`, `tutorialVersion`；中断恢复正常，关公司则重置；设置→`重新查看操作指引`只重播提示，不重复创造公司或招聘初始员工。高亮遮罩不能遮住按钮；如果场景异常/卡片被滚动遮挡，应自动滚至目标位置或提供`跳过此步`。

### 教程文案（开发可直接使用）

- TUT-01：“欢迎成为CEO，先给公司起个名字。”
- TUT-02：“CEO的性格会影响未来的成长方向。”
- TUT-03：“能力强不一定最划算，也要比较潜力和工资。”
- TUT-04：“营收是卖出去多少；利润才是扣掉成本后赚的钱。”
- TUT-05：“公司会自动经营，你可以暂停或加速时间。”
- TUT-06：“查看今年利润与现金变化，决定明年是否扩张。”
- 退出：“跳过说明” / “稍后在设置里重新查看”。

## 7.5 关键弹窗与提示

| 场景 | 标题 | 主要操作 | 安全要求 |
|---|---|---|---|
| 招聘确认 | 确认录用？ | 支付¥X并录用 | 防重按钮、余额复核 |
| 裁员确认 | 确认裁员？ | 支付赔偿¥X | 不允许“确定”默认高亮导致误触 |
| 建部门 | 创建采购部？ | 支付¥10,000 | 提示0员工无效益 |
| 扩大产能 | 扩大主营业务规模 | 投资额、预计增量 | 若需求不足明确风险 |
| 关闭公司 | 关闭公司并重来？ | 红色“永久清除本局” | 二次确认、失败不退出 |
| 经营困难 | 公司资金不足 | 查看工资费用/一次救助/重开 | 不会隐性删除档案 |
| 存档故障 | 保存失败 | 重试/保留当前界面 | 不可声称动作保存成功 |

## 7.6 空状态与错误恢复矩阵

- 首次无年度报告：`完成第一个经营年度后可在这里回看财务。`
- 候选生成失败：`暂时无法生成候选人，点击重试`；不扣现金。
- 现金不足：`还需¥X才能完成操作`，显示预计现金余额。
- 同一部门已有：`已创建此部门，可进入管理`，不再扣设立费。
- 平台认证暂不可用：按08选择可接受的安全降级，核心本地档不得静默丢失。
- 本地空间不足：`无法保存，请释放设备空间后重试`；危险操作禁止在存档不可用时继续。
- 设备改横屏：提示“请竖屏游玩”或自动在安全区域显示竖屏界面，不得出现按钮不可达。

## 7.7 UI组件复用表

`MetricCard`(title,value,trend,tooltip)，`OfferCard`(name,attrs,salary,selected)，`EmployeeCard`(status,dept,attrSummary)，`DepartmentCard`(type,enabled,staff,benefit,cost)，`ProfitLossTable`(category,amount,sign)，`ConfirmDialog`(title,description,confirm,danger)，`BusinessBottleneckHint`(type,explanation)，`TutorialOverlay`(anchor,text,skip,next)，`BottomTabs`，`RankRow`，`YearProgress`。

每个组件由ViewModel驱动，要求正常、空、加载、异常四态截图。禁止将具体金额写死在Prefab中。

## 7.8 UI验收清单

- 360宽小屏、异形屏、系统缩放变化下四Tab可点击，不产生水平滚动或裁切。
- 姓名包含10+汉字、emoji时卡片不越界；所有财务字段显示带¥和正负号。
- 录用、裁员、关闭公司都有清晰的二次确认/错误状态；按钮重复点不产生重复事务。
- 初次引导跳过/中断/重播不强制再聘2人；重开后引导重置。
- 关闭弹窗不改变经营时间；Android返回键不会误触确认。
