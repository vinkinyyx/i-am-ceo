# 《我是CEO》发布合规与素材许可清单（M3-08）

> 用途：TapTap 小游戏/移动端上架前自查。本文随版本更新；标注 ⚠️ 的项必须由实际开发者（主体）在提审前完成并负最终责任。代码侧已落实的合规设计见文末「工程已保证」。

## 1. 隐私与数据

- 本游戏为**本地单机经营**：核心存档、音频设置、自动招聘决策均只保存在设备本地（双槽存档 + checksum），**不收集账号、不联网上传用户数据、不含广告 SDK、不含内购**。
- 当前 SDK 接入状态：`CocosPlatform.getEnvironment() = EDITOR`，尚未接入 TapTap 平台与任何统计 SDK。
- ⚠️ **隐私政策**：接入 TapTap 登录/排行榜/云存档等任一联网能力前，须提供可访问的隐私政策 URL，并在首次启动显著告知；明确本地存储用途。
- ⚠️ 若后续引入 TapTap SDK，需在隐私政策列明其采集范围，并走 `assets/core/persistence` 之外的平台通道，不得把经营存档上传为用户画像。

## 2. 内容安全自查

- 无真人肖像、无政治/色情/赌博/暴力内容；公司名由本地白名单前缀随机生成（`NameGenerator`，≥30 安全趣味前缀），不渲染富文本/HTML，杜绝注入。
- 员工/CEO 姓名来自本地固定人名表；无 UGC、无聊天、无排行榜昵称（本地模拟企业为固定名）。
- 经营事件为抽象商业事件（订单增减、成本上涨、人员离职、设备损失），不影射真实企业或个人。
- 经济系统：无真实货币交易、无抽卡、无诱导付费；「CEO 救助资本」为一次性游戏内虚构资本，不收费。
