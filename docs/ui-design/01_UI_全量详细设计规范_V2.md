## 0. 交付摘要与边界
- **界面**：原有 `UI-01~UI-33` 共33个编号完整覆盖，增加 `EX-01~EX-09` 共9个现有功能视图/覆盖层，合计 **42 项界面规格**；UI-01另含NoSave/HasSave/Loading/SaveRecovery等不同状态。
- **独立素材**：179 个独立图片资源记录，已存在B06共享素材67个，新风格需重绘或适配，其余为新场景/人物/图标/装饰；另外15个必须程序绘制或逻辑构件，明确不能当图片生产。
- **游戏玩法范围**：贸易/软件/企业服务三选一、单主营、六类部门（主营+5支持）、员工/招聘/裁员、年度12个月、离线、危机、盈利里程碑、资产/年限排名。
- **已确认限定能力**：真实TapTap榜、个人云进度备份/恢复、每日与招聘页自愿激励视频券入口；状态由现有领域/平台能力决定。
- **明确不是本轮新玩法**：项目签约、复杂合作谈判、股票买卖、财务应收账款、生产库存、钻石/付费货币、公司LV、四种额外榜单、排行榜金币奖品、培训/任命/研发技能树、多行业扩张。这些出现在先前概念图中时仅供插画、构图、排版借鉴。

## 1. 视觉风格与设计系统
### 1.1 统一风格
定位：**明亮现代企业经营 × 轻半写实日式商业插画 × 简洁账本式卡片**。环境写实度稍高于Q版，人物面部与服饰一致、比例自然；蓝白金点缀，暖色办公室自然光。插画体现公司经营氛围，信息层使用低噪声白卡与原生控件。

**固定规则**：大场景仅首页/创建/部门及人才页使用；财务、排行等强信息页缩短或折叠顶部Hero；图表只做解释，完整金额和经营口径优先；一个页面不超过一个强CTA。

### 1.2 分辨率、留白及交互尺寸
| 项目 | 规格/推荐值 | 实施说明 |
|---|---:|---|

| 概念大画面 | 1080×2400、9:20 | 仅构图与宣传对照；不能直接替代Cocos UI |
| 横向页边距 | 16 | 卡内12、区间12~16 |

### 1.4 图表降噪规范
1. **资金/营收/利润**：优先三枚数字卡，金额右对齐，必要时一条趋势箭头即可。
2. **年度财务报告**：科目双列清单优先，默认不画复杂饼图；完整金额、负号、年结与预估标签必须清楚。
3. **排行榜**：前十行列表是主角；可增加Top5简洁横向比较条作为辅助，不叠多个榜型或奖金。
4. **部门产能/需求**：在同一标尺绘制两条水平进度条；标出实际值、差额，不用3D柱状图。
5. **员工能力**：使用最多3根小横条（能力、潜力、协作）；不采用六边形雷达图遮挡标签。
6. **市场景气**：只展示已有模拟器提供的景气因子；没有历史序列就不画7日折线。所有图表由Cocos原生节点动态绘制。

### 1.5 图层、人物、动效
场景层L0背景 → L1空镜环境 → L2透明NPC/CEO → L3遮罩渐变 → L4原生卡片/文字/按钮 → L5弹窗 → L6教程聚光。NPC、背景、前景需独立导出，人物不得与动态气泡合并；单次过渡100~200ms，不做复杂NPC走路或大规模3D。

## 3. 复用组件规格
| 组件 | 使用范围 | 内容结构 | 交互/布局约束 |
|---|---|---|---|
| **Shell/Header** | 所有主屏 | 公司名、年份/月、现金、设置等动态Label；顶部SafeArea留宿主空间 | 高度随设备；默认52逻辑单位；公司名过长则省略+点击看全名 |
| **BottomTabs** | UI-05~08 | 公司/部门/人才/排行四等宽Tab；选中蓝字/浅蓝底 | 视觉56~60；点击热区≥44；底部SafeArea额外占位 |
| **IllustratedHero** | UI-02~08及部分详情 | 底景 + 角色独立透明层 + 可选气泡 + 渐变过渡 | 常规140~200高；短屏可折叠至90~120；不得遮住可用按钮 |
| **MetricCard** | 首页、年报、离线、部门 | 左图标、标题、动态金额、趋势说明 | 卡内12；数值22~28；金额对齐；保持完整元值可展开 |
| **ListRow** | 排行、员工、云档列表 | 整行点击、数字列右对齐、图标或头像可独立复用 | 行高≥52；触控目标44；连续行之间有8间隔或细分隔 |
| **EmployeeCard** | 人才列表/招聘/详情 | 头像+姓名/性格+能力/成长+月薪+费用 | 不贴死文字；姓名可省略，详情显示全名；不能自动给出不存在的匹配分 |
| **DepartmentCard** | 部门 | 部门小场景+人数+成本/净贡献+状态 | 0员工无收益；已建/未建明确区分 |
| **ChoiceCard** | 公司行业、CEO性格、经营策略 | 单选高亮边框、对勾 + 一行效果说明 | 选中不仅依靠颜色；点整卡可选 |
| **TimeSpeedControl** | 首页 | 暂停/1×/2×/5×分段控制 | 选中态、禁用态和真实速率一致 |
| **ProfitLossList** | 年度报告 | 账目双列，长项自动换行，金额完整可看 | Label RESIZE_HEIGHT；固定标题/底部，正文滚动 |
| **ChartSimple** | 排行榜、趋势、财务 | 双横条/最简线图/进度条，图旁有数字 | 禁止把图表数值预烘焙成图片；没有数据不画趋势 |
| **AdvisorBubble** | 首页、诊断、事件 | NPC独立半身像 + 1~2行解说 + 可选跳转 | 长文折叠“查看说明”；不遮挡正文与按钮 |
| **ConfirmDialog** | 招聘/建部/救助 | 费用、影响、余额与确认/取消清晰 | 资金操作不得因UI复用漏掉幂等或保存失败 |
| **DangerDialog** | 裁员/关公司/删除云档 | 危险语义红色 + 二次确认 + 取消优先 | 危险按钮不能预选、双击不能多扣费 |
| **StatusPanel** | 空白/错误/未授权/同步中 | 图标+解释+唯一主恢复操作 | 不能假装网络/存档成功；状态文案平实 |
| **TutorialSpotlight** | UI-28~33 | 原生遮罩+真实锚点，导师气泡、跳过按钮 | 跳过解说不跳过必做操作；锚点不在屏幕时重定位 |
| **RewardCoupon** | EX-05/06与招聘 | 自愿广告入口+招聘费券状态 | 不领取现金，不免月薪，不在首聘引导弹广告 |
| **CloudSaveCompare** | EX-02/03 | 两个版本的年月/资产/时间并列，不用难读微型图 | 冲突确认才可能替换；不能自动合并 |

## 4. 页面明细：逐页设计规格

### B01 创建及引导

#### UI-01 · 启动页 / 继续游戏　`S00 /boot`　[P0]
- **定位/表现**：场景；清晨城市办公楼外景；无角色强制占位。
- **从上到下的布局分区**：
  1. 顶部：游戏Logo与简短标语。
  2. 中部：创业大楼纵深插画，留出Logo与开始区。
  3. 底部：新游戏/继续经营、设置或隐私入口、平台状态说明。
  4. 加载态在同一布局显示进度条，不单独烘焙数字。

- **用户动作/流转**：新游戏→UI-02；继续游戏→读取当前有效存档→UI-05或UI-14；加载失败→UI-27；隐私入口→平台政策文本。

- **行为与防误导约束**：不可因登录失败或读档异常自动开新档；仅用户显式选择创建；Loading数值动态绘制。
- **图片元素/程序绘制引用**：`ILL-S01`、`BRD-01`、`DEC-01`、`STA-01`。
- **验收要点**：当前信息应由数据绑定驱动；按钮热区和滚动可达；操作失败后仍在安全状态；无名称/金额/按钮烘焙在插画中。

## 5. 图片资源制作与导出契约
### 5.1 三类文件严格分离
1. **美术源文件**：画师或生成模型导出透明角色、空镜场景、图标等，不含动态UI文本。每个资源单独文件。
2. **Cocos实际资源**：经压缩的PNG/WebP（WebP是否兼容TapTap目标格式须验证）和SpriteFrame，9-slice配置交由Cocos。资源键保持稳定。
3. **整屏设计稿**：用于设计评审、视觉回归，只能作为参照；不允许直接把1080×2400整页PNG贴作可点击界面。

### 5.2 资源规格与命名
- 全屏启动与纯背景：1080×2400，严格9:20；背景在异形屏可安全裁切边缘，中心主题不能裁切。
- 横幅环境：1080×560～720，主角色与场景分离；普通页面中按容器居中裁剪而非拉伸。
- NPC半身立绘：720×960，透明PNG，动作范围留白10%；正面偏45度；不得截断手或头发。
- 头像：既有B06资源键不改，建议高清母版512×512、游戏候选256×256；同一角色身份保持可追踪。
- 图标：SVG设计源+192×192 PNG透明版本；列表运行时可显示40～56逻辑单位。
- 装饰贴纸：320×240或360×320透明PNG；重复使用，不创建带用户名字或金额的特版。
- 目录：`assets/resources/ui_v2/<category>/<asset_id>.png`（以清单实际 proposed_path 为准）；生产原稿与运行压缩图分离。

### 5.3 全量资源清单与优先级
本次清单共 **179条独立图片资源**：其中 **67条为原B06已有资源**（不是声称全都已符合新画风），**112条为新增或待重绘的独立画面/贴纸**。详见[素材台账](03_Asset_Registry_V2.json)，含分组、对应页面、格式/尺寸、透明背景、优先级、复用状态、旧资源键及图片说明。
**程序绘制项**：原生进度条、数值折线、报表、教程遮罩、主导航容器、文字、按钮与输入框，不进入美术生图数量。

### 5.4 一致性生图提示模板（仅生产独立素材，不做整屏贴图）
> 《我是CEO》统一风格：明亮都市职场、自然人体比例的轻半写实日式2D商业插画、细腻赛璐珞上色、现代办公空间、柔和日光、蓝白金UI配色、低噪声背景、精致但不夸张的光泽。角色沿用统一脸型、发型、服装细节与光源；场景采用同一城市及品牌视觉。严格单素材、独立导出、构图完整、指定尺寸/透明通道。
> 反向约束：不要任何文字/数字/水印/企业商标；不要从概念图复刻错字；不要把按钮、气泡、数值和插画烘焙在一起；不要Q版、赛博朋克、3D写实、过度金光。
