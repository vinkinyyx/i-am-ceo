# 《我是CEO》MVP 精简测试方案 V1.1

> 本版是基于 V1.0 315 条测试需求做的 **首发风险导向精简**。执行结果见 `CEO_Test_Result_v1_1.md`。

## 总量对比

| 维度 | 旧版 | 精简版 |
|---|---:|---:|
| 独立测试场景 | 244 | 22 |
| 详细执行案例 | 315 | 80 |
| P0 首发阻断 | 238 | 57 |
| P1 常规检查 | 77 | 23 |
| 需求覆盖 | 20/20 | 20/20 |
| UI页面检查 | 33个独立UI用例 | 33页组合式检查清单（4条组合路由案例） |
| 黄金测试 | 17个参考计算 | 重点业务抽查 + 17项公式备查；不要求17项全部做人工独立测试 |

## 文件用途

- `CEO_Test_Plan_v1_1.md` / `CEO_Test_Plan_v1_1.xlsx`：测试计划与工作簿（xlsx 含 总览/案例排期80/缺陷/门禁/证据 等 sheet，供回填状态）。
- `CEO_Test_Scenarios_22.md`：22 组场景及测试目标。
- `CEO_Test_Cases_80.md`：80 条详细可执行步骤、预期与关联（唯一来源，不再保留 csv/xlsx 副本）。
- `CEO_Test_Schedule_80.csv`：80 条案例的排期与执行结果明细（Agent 自动读写）。
- `CEO_Test_Result_v1_1.md`：本次执行的结果报告（结论、缺陷、门禁、证据索引）。
- `CEO_Test_Reduction_Rules.md` / `CEO_Test_Reduction_Review.csv`：精简原则与旧案例删减复核。
- `CEO_Golden_17_Reference.csv`：17 项黄金数值参考。
- `CEO_Requirement_Coverage.csv`：20 条需求的覆盖映射。
- `CEO_UI33_Checklist.csv`：33 页只做可达、返回、数值、触控的一次性巡检清单。
- `QA_Summary.json`：机器可读的测试结论汇总（含包体大小/哈希）。

## 判定

首发测试强调“能够从零创业、正确结算财务、长期持续经营、保存重开可用、TapTap真机能操作”，不过度测试理论上的罕见故障。

**注意**：如实际代码涉及平台认证和关键数据的高风险持久化处理，仍需由开发运行基础自动化单元测试；本版删减的是重复人工案例，不允许忽视真实发现的严重缺陷。
