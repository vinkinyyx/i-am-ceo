# 《我是CEO》隐私政策 V3

**生效日期：2026年11月4日**
**开发者：郁延鑫（个人开发者）**
**联系方式：vinkinyu@163.com**

《我是CEO》是一款由个人开发者独立制作的模拟经营游戏，通过 TapTap 平台以「普通小游戏」形式发布。本政策说明本版本的信息处理方式。云备份与公开榜单默认关闭，广告功能默认关闭。

## 一、我们收集的信息（极少）

经营数据默认保存在设备本地。玩家主动开启云备份后，存档快照会提交至 TapTap 云存档以便跨设备恢复。玩家主动开启公开榜单后，公司资产和经营年限分数会提交至对应公开榜单，并可能连同平台玩家身份信息向其他玩家展示。音频、画面设置保存在设备本地。

| 场景 | 涉及信息 | 处理方式 |
| --- | --- | --- |
| 游戏存档（公司、员工、财务、设置） | 全部经营数据 | 默认只存本地；玩家主动开启后提交到 TapTap 云存档。未开启时不上传经营存档 |
| 公开榜单 | 当前公司资产与经营年限分数、平台展示身份 | 玩家主动开启后提交至 TapTap 榜单服务；公开显示与保留由平台榜单规则决定 |
| TapTap 登录 | 平台登录 | 由 TapTap 平台提供，按平台当前隐私政策处理；本游戏不主动读取稳定账号标识 |
| 音频、画面设置 | 开关状态 | 仅保存在设备本地 |

本版本没有启用广告组件。云备份与公开榜单也默认关闭，须由玩家主动启用并满足平台条件后才会提交相应数据。当前平台账号关联、云端保留期限、地区、删除能力及榜单实际展示规则以 TapTap 平台当前配置和政策为准，本政策不承诺本游戏端无法访问或特定保留期限。

## 二、第三方 SDK 说明

本游戏使用 TapTap 小游戏登录、云存档与（玩家主动开启时）公开榜单能力；不主动获取 openid、unionid、昵称或头像。公开榜单会按平台实际接口展示玩家身份，关闭游戏内同步不一定删除平台已提交记录。广告组件默认关闭。TapTap 平台信息处理适用 [TapTap 隐私政策](https://www.taptap.cn/privacy-policy)。

## 三、信息的存储与保护

- 经营数据：默认本地保存；开启云备份后由 TapTap 云存档跨设备保存。
- 登录：由 TapTap 平台提供，按平台当前隐私政策处理。
- 本版本广告功能关闭；本政策不对未来广告 SDK 的数据传输作未经核实的承诺。
- 榜单：开启后提交当前公司两项分数和平台展示所需身份信息。关闭后不再提交，但已提交数据是否可删除以平台功能为准。

## 四、未成年人保护

本版本不含内购，广告功能关闭。若后续版本启用广告，将遵循平台未成年人保护及广告展示规则。游戏时长与登录限制按 TapTap 平台当前要求执行。

## 五、你的权利

- **删除数据**：卸载或清除游戏数据可删除本地存档；云档和榜单记录需通过 TapTap 平台支持的功能处理。
- **撤回同意**：首次启动的隐私告知弹窗中，你可以选择不同意并退出游戏；同意后也可通过卸载随时退出。
- **查询与更正**：平台账号、云档和榜单数据的相关权利以 TapTap 提供的渠道为准；如有疑问可通过 vinkinyu@163.com 联系我们。

## 六、政策更新

如本政策发生变更，我们将在游戏内作出提示并更新版本号。重大变更时，会在游戏启动时再次征得你的同意。

## 七、联系我们

如对本政策或信息处理有任何疑问、意见或投诉，请联系：vinkinyu@163.com。我们将在收到后 15 个工作日内回复。
