# 《我是CEO》TapTap 竖屏动态宣传片 V1.0

## 交付说明

- 成片：`CEO_Animated_Promo_9x16_720x1280_26s.mp4`
- 时长：26秒，720×1280，9:16，24fps，H.264 + AAC，MP4
- 类型：原创连续帧2D动画，**不是静态图轮播**。包含原创建筑生长、人物行走及挥手、招聘卡片运动、部门逐项生成、数据计数和增长曲线、市场下降与恢复等运动设计。
- 原创背景音效：`original_music.wav`，在 MP4 中已经合成。
- 分镜预览：`storyboard_contact_sheet.jpg`。
- 制作源代码：`build_video.py`；动画人物头像依赖随包 `SourceAvatars/` 的3张PNG。需要 Pillow、NumPy、SciPy 和 FFmpeg。

## TapTap发布说明

本文件是**概念CG/游戏宣传动画**，并非游戏引擎实机录屏。不要把它作为 TapTap 要求的“游戏实机录屏”提交；实机视频须等游戏完成后从真实运行环境录制。

TapTap 小游戏官方物料指引要求竖屏实机录屏采用9:16、至少720×1280、MP4、H.264/HEVC，且500MB以内。视频分辨率/编码达到这一技术基准，但内容类别仍为概念宣传片。

官方文档：https://developer.taptap.cn/minigameapidoc/quick-start/guide/game-publish/material/

## 使用建议

- 开发者可提取本视频的音频与画面作为独立宣传资产，但不可将概念画面冒充已实装的游戏功能。
- 片内演示数值只是镜头内容，不是运行的经营引擎实时输出。
- 所有动画画面和音轨均由本包程序生成；使用第一阶段既有员工头像图形素材。
