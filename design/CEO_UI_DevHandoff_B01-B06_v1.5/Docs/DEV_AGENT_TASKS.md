# UI 开发 Agent 实施任务与验收流程

## D0 资产入库（先完成）

- [ ] 确认根目录 `AGENT.md` 与原项目业务文档存在；不要用本包覆盖工程根目录。
- [ ] 检查Cocos版本、项目既有目录及资源命名冲突。
- [ ] 合并 `CocosDropIn/assets/resources/ui/` 的67张PNG；重新导入后生成 `.meta`。
- [ ] 按 `asset_registry.json` 加载至少头像1张、部门1张、导航1张、按钮底板1张，确认透明度和尺寸。
- [ ] 决定是否把UIComponents转原生圆角卡/九宫格；此步骤不是资源包已完成的功能。

## D1 B01 创建流程（先于主界面）

- [ ] UI-01和启动四态；存档失败可重试。
- [ ] UI-02随机/自定义公司名、行业单选、输入校验。
- [ ] UI-03姓名、CEO性格三选项，创建事务仅一次注资。
- [ ] UI-04三候选对比、逐个录用两人、每次录用防重复扣款。
- [ ] UI-28/29/30 指向真实控件的教程遮罩；可跳过说明，不跳过必做业务。
- [ ] 360×640、375×812、428×926 竖屏截图；全部点击热区≥44。

## D2 B02 核心经营（年度系统已有后）

- [ ] UI-05四个主指标和年份/月/倍速渲染；区分本期累计与全年预估。
- [ ] UI-06部门列表按动态数据刷新；未建部门与已建部门区分。
- [ ] UI-07员工列表分页/可滚动。
- [ ] UI-08模拟经营排名，使用“模拟企业”标识。
- [ ] UI-31/32新手提示层：可定位和解除遮挡。
- [ ] 4Tab保证安全区、横竖屏限制、返回路径正确。

## D3 B03 员工与部门（接内部事务命令）

- [ ] UI-10/11详细资料与部门贡献；数值不写死。
- [ ] UI-16/17报价→录用确认→提交→存档；重复点击只能扣一次。
- [ ] UI-18裁员赔偿确认，显示补偿费用与人员影响。
- [ ] UI-19新建部门0员工无效益，需支付创建费。
- [ ] UI-20/21/22投资、经营策略、人数目标；手动锁定不应自动裁员。
- [ ] 每个交易过程都有余额不足、已处理、保存失败视图。

## D4 B04 财务/风险

- [ ] UI-09完整年度报表字段，以领域引擎结算结果为准。
- [ ] UI-14离线结算只读展示，不能重复领奖/双算。
- [ ] UI-15经营困难提示，公司亏损不等于立刻破产。
- [ ] UI-23/24指标帮助和排行榜说明。
- [ ] UI-25连续3年盈利提示，不中断后续自由经营。
- [ ] UI-26一次性救助，必须成功存档并正确更新现金与实收资本。
- [ ] UI-33第六步新手引导。

## D5 B05 设置/关闭/恢复

- [ ] UI-12游戏设置、引导重放、隐私入口。
- [ ] UI-13关闭公司二次确认；关闭后runId改变、旧命令不可复活、旧存档不会回填。
- [ ] UI-27存档失败提示、重试、防丢档，不给出假的“保存成功”。

## 跨页面门禁

- [ ] 所有钱用整数元，呈现格式与业务引擎一致。
- [ ] 所有列表和点击控件能触摸操作，确认弹窗不能误触。
- [ ] 文案动态渲染，公司名/CEO名超长时可滚动或截断并可查看全文。
- [ ] 逐页面按 ScreenStates 状态矩阵截图、做真实功能验收。
- [ ] TapTap小游戏真机内核和Cocos工程构建验证，不能用静态PNG通过来代替。
- [ ] 提交改动文件、测试证据、已知问题及下一任务。
