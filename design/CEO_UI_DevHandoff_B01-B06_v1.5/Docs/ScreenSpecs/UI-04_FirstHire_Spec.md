# UI-04 首次招聘

- 所属：第一阶段MVP / B01。
- 目标分辨率：375×812逻辑像素，750×1624导出；触控热区不少于44×44。
- 画面功能：显示三名候选人并选择2名；属性、成长潜力、性格、月薪、招聘费透明展示；汇总招聘费按选中的2人计算，确认时单次扣款。
- 状态验收：0/2、1/2、2/2、候选失效、现金不足、重复点击录用。
- 正式开发稿：B01_Onboarding/Screens/UI-04_FirstHire.svg（PNG同名）。
- 所有动态姓名、价格、属性使用Cocos Label/输入组件，PNG只是视觉参考。
