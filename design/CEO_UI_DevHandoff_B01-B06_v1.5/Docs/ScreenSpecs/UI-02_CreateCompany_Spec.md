# UI-02 创建公司

- 所属：第一阶段MVP / B01。
- 目标分辨率：375×812逻辑像素，750×1624导出；触控热区不少于44×44。
- 画面功能：三个行业单选，显示3个可换批的推荐公司名，允许手动输入（2—12字）；下一步前须有有效行业及名称。
- 状态验收：无效名称、空名称、选中推荐名、手动输入、换批、按钮禁用。
- 正式开发稿：B01_Onboarding/Screens/UI-02_CreateCompany.svg（PNG同名）。
- 所有动态姓名、价格、属性使用Cocos Label/输入组件，PNG只是视觉参考。
