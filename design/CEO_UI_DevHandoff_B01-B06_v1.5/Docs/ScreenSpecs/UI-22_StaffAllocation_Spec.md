# UI-22｜部门人员配置

- 所属批次：B03
- 路由或组件：`StaffingDialog`
- 画布：375×812逻辑像素；提供750×1624 PNG + 375×812 SVG viewBox。
- 对应基线：第一阶段MVP；不得增加集团/跨行业/上市/广告付费模块。

## 视觉组成

参见同文件夹 `UI-22_部门人员配置.svg`；本文描述交互行为与运行时数据。静态画面全部为审阅示例，不代表可直接部署的Cocos Prefab。

## 玩家操作

AUTO与LOCKED选择、目标人数设置；锁定不立即裁员。按钮以至少44×44逻辑像素为实现目标，滚动和安全区由Cocos原生节点处理。

## 数据绑定

公司名、年度、员工名、岗位、工资、招聘费、部门状态、财务数值、排行榜成绩等均从ViewModel获取，禁止把静态稿演示数值硬编码到业务中。

## 必须实现的状态

自动/手动/人数异常/保存失败。此外适用时均应有Loading/Empty/Error、重复点击保护和保存失败的明确反馈。

## 交互安全与验收

1. 任意涉及资金或不可逆操作的确认动作，在正式提交时二次校验并幂等。
2. 从该界面返回、重复打开、进程暂停恢复不重复执行业务事务。
3. 360×640、375×812、390×844和428×926设备进行真机或模拟器布局验证。
4. 底部导航、输入框和弹窗不得被系统安全区及软键盘遮挡。
5. 动态文本用Cocos Label/EditBox渲染；SVG仅为版式源稿，不作为真实业务界面。

## 视觉验收

- 蓝青、白卡片与浅灰蓝底遵守B00设计参数。
- 盈利与亏损同时显示正负符号和明确文字。
- 列表和弹窗使用统一圆角、字号层级、分隔线与按钮样式。
- 与业务需求发生冲突时，以 `docs/` 的财务与业务状态机为准，记录差异并修正文案。
