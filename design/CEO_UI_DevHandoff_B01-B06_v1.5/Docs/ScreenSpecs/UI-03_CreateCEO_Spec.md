# UI-03 创建CEO

- 所属：第一阶段MVP / B01。
- 目标分辨率：375×812逻辑像素，750×1624导出；触控热区不少于44×44。
- 画面功能：CEO姓名可自填或随机生成（2—8汉字）；性格仅进取、稳健、亲和；显示商业、管理、财务属性；不可增加第4种性格。
- 状态验收：空姓名、姓名非法、切换性格、选中态、按钮禁用。
- 正式开发稿：B01_Onboarding/Screens/UI-03_CreateCEO.svg（PNG同名）。
- 所有动态姓名、价格、属性使用Cocos Label/输入组件，PNG只是视觉参考。
