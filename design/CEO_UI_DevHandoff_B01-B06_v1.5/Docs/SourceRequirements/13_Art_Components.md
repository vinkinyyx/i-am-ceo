# 13｜第一阶段2D视觉资源、组件规格与交付约定

## 13.1 资产制作边界

《我是CEO》第一阶段以**信息面板+部门组织卡+人才头像**为主，不做3D场景、地图、人物逐帧动画、战斗特效或CG过场。所有汉字、玩家自定义名称、工资和财务金额一律**运行时字体渲染**，不得烘焙在图片素材中。软件发布物料与真实游戏界面用统一品牌，不把尚未实现的集团/上市内容画进首发宣传。

## 13.2 视觉方向（首轮可执行规范）

- 2D轻卡通经营UI，清爽中性蓝/青主色、浅色卡片、深灰正文，财务正负有文字与图标辅助区分。
- 背景以纯色/微弱纹理为主，所有UI卡片使用Cocos原生矩形/圆角九宫格，减少图片依赖。
- 头像使用**通用模块化角色头像**，不追求上百个独立脸；默认8个头像外观，通过性别中性、发型/服装配色变体得到至少24种组合。不得将脸部用于推断真实人口身份信息。
- 公司名字幽默可以通过文案体现，但界面整体不做夸张广告风格；优先财务可读性。
- 参考调色（不是强制锁版）：主色`#3668B2`，辅色`#5D9F8C`，背景`#F5F7FB`，深字`#273244`，弱字`#697386`，危险`#C75353`；上线前通过真机色彩/对比测试。

## 13.4 组件尺寸与布局参考

以375×812为设计坐标，顶部安全区动态、底部安全区动态：

| UI组件 | 建议尺寸/行为 | 交互 |
|---|---|---|
| 顶部公司栏 | 高52—60（不含安全区） | 点击设置进入D04 |
| 财务指标卡 | 每列约112宽，间距8 | 点击“?”显示定义 |
| 主营业务卡 | 宽度跟随可用区域，高120—170 | 点进主营业务部/投资 |
| 部门卡 | 一列竖排，高110—150 | 点击详情、展开操作 |
| 员工卡 | 单列高100—140 | 点击人员详情 |
| 候选卡 | 单列高140—180，允许滚动 | 点选与录用按钮分开 |
| 底部Tab | 图标24—28，热区≥44，整体高56—64+安全区 | 4入口始终可达 |
| 确认弹窗 | 宽度≤页面宽−32，按钮高≥44 | 危险确认与取消区分 |
| 年度进度 | 条高6—10，数字显示年/月与倍速 | 不依靠动画显示实际结算 |

Cocos组件只能监听可靠的Button触摸事件；滑动ScrollView时不得误触卡片内裁员/关闭按钮。键盘打开时页面要上移/可滚动，使自定义公司名、CEO名输入和确认按钮不被遮住。

## 13.5 命名与导出规范

- PNG优先；不必要照片和视频不进入游戏首包；压缩小图集减少drawcall。
- 文件命名`lower_snake_case.png`；头像按固定ID引用，不把玩家输入做文件名。
- 同类图标统一有效画布与边距，不混用16:9图当方形图标，任何图标不得截掉边缘。
- 美术Agent提交`asset_manifest.csv`：`assetId,filePath,source,promptOrDesigner,license,width,height,format,reviewStatus`；素材授权不明的禁止进入上线包。
- 严禁从其他游戏直接抠图或复制受版权保护的专有UI资源。

## 13.6 视觉QA

- 所有图标纯色背景/亮色背景下均可辨认；不出现模糊或透明边缘毛刺。
- 相同类型卡片的图标尺寸、圆角、间距与文字baseline保持一致。
- 招聘、裁员、关闭公司等操作的确认按钮清晰而不会被滚动遮住。
- 360×640、375×812、428×926中中文与大额数字展示都不溢出。
- 游戏截图与真实已完成的UI一致，不宣传第二阶段子公司/集团功能。
- 静态UI无需每个元素生图；优先引擎原生文本/图形，减少包体和返工。
