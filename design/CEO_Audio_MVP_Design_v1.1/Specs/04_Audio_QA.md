# 04｜音频验收标准与测试清单

## 静态文件检测

- [ ] 所有16个文件按 manifest 的相对路径存在，命名完全一致，文件可解码，无0字节文件。
- [ ] BGM_01、BGM_02无缝循环试听至少连续5次，没有明显接缝、爆音或静音断层。
- [ ] 16个文件均有合法商业使用与再分发证据；音效无明显第三方版权识别音。
- [ ] 资源大小测试目标：游戏第一阶段音频压缩文件总和建议不超过3MB（项目性能目标，不是平台硬性限额）。

## 运行与场景测试

- [ ] AQA-01：首次进入（无用户交互）不强制播放；点击后可以正常听到音乐。
- [ ] AQA-02：从创建公司到创建CEO、首次招聘，BGM不中断且不重新从头播放。
- [ ] AQA-03：进入公司首页后切换为经营曲，部门、人才、排行榜切换不重新启动。
- [ ] AQA-04：UI-04 首次招聘、UI-17录用，只有扣费/入职成功后才播放招聘反馈。
- [ ] AQA-05：UI-18 裁员完成时播放中性音，确认取消时不能播放完成音。
- [ ] AQA-06：快速点击、刷名字、1×/2×/5×连续切换时无大量叠音。
- [ ] AQA-07：分别播放正利润和负利润年度报告，听感区分且不会提示破产。
- [ ] AQA-08：同一年度报告重复打开时不重复播放年度短乐。
- [ ] AQA-09：连续三年盈利的短乐每轮公司仅触发一次。
- [ ] AQA-10：后台/锁屏后不继续发出音效；回前台按设置恢复，不重复起播多路BGM。
- [ ] AQA-11：离线3年汇总只给一次必要提示，不把36个月逐月音效补播。
- [ ] AQA-12：关闭公司并重新开始后，旧年度音效状态不残留，音量开关恢复默认。
- [ ] AQA-13：音乐关闭仅关闭音乐；音效关闭仅关闭音效；两个都关闭完全静音。
- [ ] AQA-14：任意一个音频文件缺失/加载失败，游戏仍可创建公司、经营和存档。
- [ ] AQA-15：不同性能Android手机上没有突然升音量、并发爆音、音频卡顿。
- [ ] AQA-16：暂停经营时BGM仍正常播放（游戏暂停≠静音），手机切后台例外。
- [ ] AQA-17：资金危机只提示一次，不持续报警造成挂机干扰。

## 发布门禁

- 交付16段真实音频、可证实的权利记录、性能和兼容性证据后才能标记“音频已完成”。
- 宣传片已有26秒音轨只是独立参考，不自动视为游戏内长循环BGM。


## V1.1新增｜UI-12声音总开关验收

| 用例 | 操作 | 必须通过的结果 |
|---|---|---|
| AQA-18 | BGM与短音效播放时关闭“全部音乐与音效” | 全部立即静音，当前音效不残留 |
| AQA-19 | 总开关关闭后点击按钮、招聘、结算 | 所有业务照常执行，无任何BGM/JNG/SFX |
| AQA-20 | 分项音乐关、音效开，再关总开关后打开 | 分项仍保持音乐关/音效开，不擅自覆盖 |
| AQA-21 | 总开关关闭后退出并重进 | 初始没有声音，总开关状态保持关闭 |
| AQA-22 | 总开关打开后进入正常经营 | 遵从首触摸解锁与分项配置，只恢复需要的BGM |
| AQA-23 | 静音中触发数个年度事件后打开总开关 | 不补播离线或静音期间的音效队列 |
| AQA-24 | 快速连续切换开关、切后台再切前台 | 不叠加、不漏音、不重启重复BGM |
| AQA-25 | 在游戏设置中选择关闭公司并重新创建 | 按项目重置规则恢复默认开关，无旧音频状态污染 |

**验收前提：** 必须在Cocos编辑器、TapTap开发环境、目标Android真机分别确认声音开关行为；只检查配置文件不等同于运行验收。
