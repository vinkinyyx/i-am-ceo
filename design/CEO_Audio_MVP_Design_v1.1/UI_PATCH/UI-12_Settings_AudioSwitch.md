# UI-12 游戏设置｜声音总开关 V1.1 增量规范

## 页面布局

- **声音设置**（一级分组）
  1. **全部音乐与音效**（一级开关，默认开）——说明：关闭后游戏完全静音
  2. **背景音乐**（二级开关，默认开）——用于 BGM-01、BGM-02
  3. **操作与提示音效**（二级开关，默认开）——用于 JNG-01～03、SFX-01～11
- 其他游戏设置、回看引导、隐私、关闭公司等现有项目不变。
- 开关控件触控区域不低于 44×44 逻辑像素；文字、状态、无障碍标签需动态显示。

## 状态与行为

| 场景 | 声音结果 | 子开关显示 | 存储 |
|---|---|---|---|
| 首次启动且允许音频 | 仅首次触摸后开始符合条件的音频 | 默认开/开 | 写入默认值 |
| 总开关从开切关 | **立即全部静音**，包括已在播放的短音效 | 置灰，保留原值 | 立即保存 |
| 总开关从关切开 | 根据分项偏好恢复新触发声音；BGM可续播 | 恢复可操作 | 立即保存 |
| 背景音乐关闭 | 立即关闭BGM，其他音效继续 | 操作与提示音效保持 | 立即保存 |
| 操作与提示音效关闭 | JNG/SFX全部静音，BGM继续 | 背景音乐保持 | 立即保存 |
| 切后台/离线结算 | 不自动播放或补播短音效 | 不修改偏好 | 保持 |
| 关闭公司并重新创业 | 按已确认存档重置规则恢复三个开关默认值 | 开/开 | 覆盖保存 |

**音频优先级：** `masterEnabled` > `musicEnabled / effectsEnabled` > 前台与用户手势限制。无声音仍必须给出视觉确认反馈。
