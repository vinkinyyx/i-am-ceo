## 2. 统一画风与可复现参数

- **画风**：轻半写实日式 2D 商业插画，软赛璐璐上色，细线收边，不做厚涂。
- **光向**：暖日光自**左侧窗户**进入并向右下投光；暗部偏冷蓝灰，人物左亮右暗与场景一致。
- **色板**：主蓝 `#3668B2`、深蓝 `#315FA4`、正文 `#243247`、次文 `#53647A`、底色 `#F4F6FA`、暖光 `#FFE3B4`、原木 `#C79A6B`。
- **金色**：仅胸针、镜架、领带扣、书脊等小面积点缀，不承担任何信息。
- **比例**：头身比自然（半身立绘头高约占画幅 1/4），肩宽与头宽约 1.9:1；头像取景头高占画幅 70%。
- **禁止项**：公司名称、金额、等级、按钮、对白框、排行行、图表、品牌字样、水印、虚构游戏币。场景与立绘内**零文字烘焙**。
- **复现**：出图提示词与绿幕约定见 [src/prompts.json](src/prompts.json)；换个文件名即可重跑同一流程。

### 3.1 场景裁切复核

- 容器 **343×160**（常规首页横幅）：cover 缩放 0.3176，可见源图 `x 0..1080, y 65..569`。
- 容器 **343×96**（短屏首页横幅）：可见源图 `x 0..1080, y 218..521`。
- 两档均保留：左侧窗户与城市天际线、中部边柜与画框、前景桌面与电脑、右下地面暖光斑；右侧约 1/3 为人物站位，两档裁切后均不出现被切断的关键物体。
- 复核图：[02_场景裁切_343x160](preview/02_场景裁切_343x160.png)、[03_场景裁切_343x96](preview/03_场景裁切_343x96.png)。

### 3.2 透明边缘复核

- 浅底 `#F4F6FA`：[04_透明边缘_浅底](preview/04_透明边缘_浅底.png)；深底 `#243247`：[05_透明边缘_深底](preview/05_透明边缘_深底.png)。
- 结论：发梢完整无锯齿断裂，手指与袖口未破洞，白西装外沿无绿边/灰边，头像肩线无残留底噪。切图按绿色主导度阈值 26/92 线性羽化并做去绿溢色。
- 立绘顶部保留 30px 透明余量，底部为半身自然切边（由容器或渐变遮罩收口）。

### 3.3 分层与合成

- 背景与人物为独立文件，运行时叠放：场景 cover → 人物 contain 贴底 → 程序渐变/原生文字层。
- 合成验证：[06_合成横幅_343x160](preview/06_合成横幅_343x160.png)、[06_合成横幅_343x96](preview/06_合成横幅_343x96.png)（左浅色遮罩仅模拟文字层占位，图内未绘制任何文字）。
- 360 宽手机观感：[07_360宽观感](preview/07_360宽观感.png)。窗口天际线、白西装与蓝衬衫、桌面电脑、右侧绿植在缩略后均可辨；人物与暖光墙面轮廓分离清楚。

## 4. 图标状态规范

- 两态共用同一组几何：屋顶 `24,16,144,26 r9`；主体 `40,38,112,136 r6`；窗 `28×24 @(62,60)/(102,60)`；门 `83,136,26,38`。
- 选中：深蓝渐变填充 + 白色开窗与门。
- 未选中：14px 灰蓝描边（内缩 7px，**外沿与选中态填充外沿完全重合**）+ 同尺寸灰蓝窗与门。
- 实测两态包围盒均为 `[21,13,171,177]`，替换时不会产生尺寸跳动。
- 笔画按 20–24px 展示尺寸反推；低于 20px 时开窗细节会合并，建议展示尺寸不低于 22。

```

├─ png/        运行用导出图（6 个，可直接导入）

├─ tools/      build.py / preview.py / manifest.py / render.cjs / measure_report.json
└─ manifest.json
```

重新生成：`python tools/build.py` → `python tools/preview.py` → `python tools/manifest.py`（依赖 Pillow、numpy、playwright-core + 本机 Chrome）。
