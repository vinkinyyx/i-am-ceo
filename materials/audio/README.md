# 《我是CEO》音频维护

## 现行素材与接入

当前运行包有 16 项声音，包含创业和经营两首 BGM、三段年报及里程碑短乐、11 条交互音效。正式资源在 [Cocos 音频目录](../../assets/resources/audio/)，事件与设置基线在 [音频配置](../../assets/resources/config/audio/)，运行实现见 [AudioManager](../../assets/scripts/audio/AudioManager.ts)。`Tools/generate_original_audio.py` 在 `build/audio-production/` 生成人工验收用母版、试听输出和清单。运行时以 Cocos 配置和 JS 实际资源键为准。

- 创业流程播放 BGM_01，经营及其子页连续播放 BGM_02，同轨跨页不重复播放。音效通道承载 JNG 和 SFX。
- 首次真实交互后解锁声音。支持总开关、分类开关、后台暂停和前台按设置恢复。经营速度不改变音乐节拍；离线多月不逐条播放提示。
- 招聘、部门创建、裁员等成功声只在业务提交后播放。失败使用失败提示，不播放成功 SFX。
- 音乐与音效为程序化原创合成，技术检测记录见 [QA_REPORT.csv](QA_REPORT.csv)。真机须复核开关持久化、前后台、峰值与循环间隙，按实际机型记录。MP3 循环不能仅靠静态参数宣称无缝。

### 为什么只要16项

1. B01创建公司/CEO/首次招聘共享一首创业BGM。
2. B02—B05的日常经营、部门、员工、排行榜和财务界面共享一首长循环BGM。
3. 成功/亏损/成就各用极短乐句，避免因频繁结算不断换背景曲。
4. 11个通用音效覆盖全部必要交互；未指定操作原则上复用，不单独制作新文件。

### 音乐制作

### 整体听感

- **风格**：轻卡通、现代企业、清新明亮、松弛有秩序；接近舒适办公室经营模拟的听感。
- **主奏**：电钢琴／钢琴、马林巴／钟琴、轻木吉他、短促拨弦、柔和合成器Pad；轻电子鼓和少量低音。
- **不需要**：人声、歌词、交响大片、大型鼓组、战斗音乐、激烈EDM、广告式强噪声、赌场式中奖音。
- **统一性**：创业曲与经营曲使用相近的四音识别动机；盈利/亏损/目标短乐用该动机变奏，形成品牌听觉辨识。
- **低疲劳**：无长时间刺耳高频、突发巨响；无手机铃声、收款到账提示音的直接模仿。

### BGM_01 创业启程

- 约 60 秒，BPM 108（建议区间 100—115），明亮、好奇与温柔的创业期待感。
- 启动和命名过程易停留，整首可无缝循环、无结束感，开头不超过2秒进入旋律。
- 控制旋律密度，避免玩家输入姓名和对比员工时分心。

### BGM_02 日常经营

- 约 96 秒，BPM 98（建议区间 90—105），低强度活泼办公室律动。
- 适合长时间挂机，重复听10—20分钟不烦；鼓点轻、低频不冲击。
- UI-05/06/07/08以及多数弹窗共用；切换页面保持同一播放进度。

### 3段JNG短乐

- JNG_01盈利：约2.5秒，明亮小上行；不使用大段胜利音乐。
- JNG_02亏损：约2.5秒，小下行、安静，强调调整空间，不是Game Over。
- JNG_03连续3年盈利：约4秒，轻庆祝、明确结束，音尾自然衰减。

### 11条SFX

- 以“轻触、纸卡、软木、柔和数字合成”统一质感。
- 单个音效建议峰值低于 -1 dBFS；近似一致的主观响度，避免点击声过大。
- 重要成功音效不超过1秒；普通点击不超过0.2秒，操作迅速、轻量。
- 裁员音效保持中性；亏损警告不发出连续警报。

### 输出与交付

1. 每个素材先交付试听版（MP3），经一次整套听感校对后交付成品。
2. 提交源WAV（44.1kHz，16/24bit）及建议运行时压缩版（BGM/JNG：MP3 96—128kbps；SFX：MP3 64—96kbps）；真机测试后再确定最终码率与实际格式。
3. BGM必须制作**可无缝循环**的版本，不得保留开头空白或明显尾音截断；可另交可听结束版，但不计入第一阶段运行资源。
4. 不允许使用未经授权的已发行曲目、知名游戏曲目直接翻制或“几乎一样”的旋律；保留商业使用及再分发授权证明。
5. 文件名精确匹配 `assets/resources/config/audio/audio_manifest.json`；音乐不包含音频水印、平台品牌语或台词。

## 质量检查

### 静态文件检测

- [ ] 所有16个文件按 manifest 的相对路径存在，命名完全一致，文件可解码，无0字节文件。
- [ ] BGM_01、BGM_02无缝循环试听至少连续5次，没有明显接缝、爆音或静音断层。
- [ ] 16个文件均有合法商业使用与再分发证据；音效无明显第三方版权识别音。
- [ ] 资源大小测试目标：游戏第一阶段音频压缩文件总和建议不超过3MB（项目性能目标，不是平台硬性限额）。

### 发布门禁
