# 《我是CEO》全量美术资产生产说明 V2.0

> 本文件配合《UI全量详细设计规范》及Excel使用。

## 数量口径

本台账共 **179 个独立图片资源**（旧B06 67，新建 112）；另有 **15 项仅程序生成的动态控件/资源组**，不计入绘图工作量。
资源条目不等于必须同时重新绘制的数量；旧资源待逐项评审后重绘，单套角色可用一致的模型与换表情降低成本。
## 批次优先顺序

1. P0-1：启动/首页/创建/首聘5张主视觉 + CEO、HR、助理、导师等NPC + 四Tab图标换肤。
2. P0-2：6部门小场景 + 24个员工头像风格统一 + 招聘与排行专用贴纸。
3. P0-3：年报、异常、离线、广告券、云备份/真实榜所需状态小插画。
4. P1：事件场景、人物表情、市场解释插画与局部装饰。
## 美术输出要求

- 角色：720×960 PNG透明；人物一致性核查，额头、手、发饰、饰品不裁切。
- 背景：横幅1080×560~720，启动1080×2400；不包含动态字和按钮，左右保留裁切空间。
- 图标：192×192透明PNG+可编辑SVG；简化造型，弱光泽，不糊边。
- 输出拆层：空景、人物、气泡尾巴、按钮背景（如确需图）、场景贴纸分别存文件。
- 不应生产：动态折线图、金额卡数字、排名行、时间进度、四Tab文本、教程遮罩、弹窗整体、随机公司名。

## 资产验收要点

- 每个文件名与台账ID唯一对应；图片实测尺寸/通道必须与登记一致。
- 主场景与人物分层，角色多表情不改变人物身份；全部无需OCR纠错。
- 在浅底与深底、75%缩小预览、360宽真机上检查清晰度。
- 旧B06素材统一保留原resourceKey，替换前先在测试分支验收，避免Cocos资源引用失效。
- 迭代时先做小批示例再全量生成；本交付并未制作台账中的所有图片资源。
