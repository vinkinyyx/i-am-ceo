- `03_UI_图片素材全量清单_V2.xlsx` / `03_Asset_Registry_V2.csv`：图片制作排期、资源唯一ID、规格和复用。

## 首要工作约束
1. 阅读本仓库根 `AGENT.md` 与 `docs/我是CEO_项目总览.md`，尤其是§1/8/21/24.14/29；以权威领域合同和本轮已确认风格为准，不建立第二套经济规则。
2. 不增加5个底部主Tab；四主Tab仍为公司/部门/人才/排行。云/广告/真榜是原有页面的子视图。
3. 保留现有Cocos Creator 3.8.8、TypeScript、领域Facade；先做可复用UI组件，再由ViewModel绑定页面，所有动态文案/金额禁止烘焙在PNG。
4. 从`assets/resources/ui/`的67张旧B06资源开始风格检查：资源键不改，视觉不符需按台账重绘，别把旧图直接认定为新画风已完成。
5. 新增图片按`asset_id`生成，背景和角色分开。没有图片时可用形状占位，但不要伪造已生产素材。
6. 人物、公司名、时间、收入、利润、排行榜、广告结果、云备份状态均来自真实游戏状态；示意原稿不等于新玩法授权。
7. 严格检查小屏SafeArea、4Tab、长金额不截断、触区≥44及间距≥8；风险确认、广告券、云恢复遵守业务幂等。

## 推荐开发顺序（不要并行过度工程化）
- D0：核对既有UI资源引用和页面路由，记录映射。仅替换已确认的视觉组件，不动业务核心。
- D1：公司首页/部门/人才/排行榜原生布局，三张重点页面形成截图并复核。
- D2：创建流程、招聘对比/确认/员工详情、财务年报与离线报告。
- D3：设置/云备份/真榜/广告券/危机与危险弹窗的真实状态。
- D4：P1事件、市场解释卡与人物表情，最后做轻微动效。
- D5：用QA-01..QA-18验收；构建与真机/平台条件分开标记，不能把静态稿当上线通过。
