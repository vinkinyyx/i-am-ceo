# 《我是CEO》TapTap商店素材 — 第二批 V2.0

## 使用方式

1. `01_StoreCandidates/` 是独立输出的图标、宣传图和封面候选，请逐张人工复核标题与内容，再根据最新 TapTap 后台规则提交。
2. `02_DesignConcepts_NotForUpload/` 是本轮重新探索的概念拼版；它们不是可直接上传的独立宣传图。
3. `03_UIConceptScreens_NotGameplay/` 是此前 UI 设计稿，**不是游戏实机截图**。游戏开发完成后必须替换成真实运行画面。
4. `04_Documents/ASSET_MANIFEST.csv` 逐文件列出格式、尺寸、用途、发布状态与SHA256。

## 设计与内容边界

- 第一阶段只展示公司创建、CEO、单主营业务、员工招聘、部门和年度盈利；不得宣传子公司、IPO、虚拟钻石或体力等未实现玩法。
- 宣传图除《我是CEO》名称外不应添加其他文案。
- 普通商店与小游戏物料要求可能不同，以当前开发者后台为准。
- 本批部分独立候选图从已生成的高分辨率品牌插画重新裁切适配，用来补足本轮概念拼版的单图交付，不应误称为全新逐图绘制。

## 尚未满足的正式上架素材

- 至少3张真实游戏实机截图（当前仅有UI设计示意）。
- 实机录屏（小游戏官方素材指南列为必备）。
- 按具体后台要求确认封面、图标与宣传图。
